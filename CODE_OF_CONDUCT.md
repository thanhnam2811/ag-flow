# Code of Conduct

ag-flow is an open-source project intended for constructive technical collaboration.

Be respectful, specific, and focused on the work. Disagreement about architecture, agent behavior, benchmarks, or workflow design is welcome; harassment, personal attacks, discrimination, threats, and deliberate disruption are not.

When giving feedback:

- criticize ideas and behavior, not people
- provide reproducible examples when possible
- distinguish measured results from assumptions
- respect maintainers' decisions about project scope

Maintainers may edit or remove abusive content and restrict participation when necessary to keep the project productive and safe.

For sensitive security reports, follow `SECURITY.md` rather than posting publicly.
